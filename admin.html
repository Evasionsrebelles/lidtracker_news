📝 Comment créer un token :
  1. Allez sur github.com/settings/tokens
  2. Cliquez sur "Generate new token (classic)"
  3. Donnez un nom (ex: "News Admin")
  4. Cochez repo (accès complet aux repos privés et publics)
  5. Cliquez "Generate token" et copiez-le ici
